# MyMuse – האתר החדש

Next.js 16 + Payload CMS 3, באותו מבנה של threebears-2026. אפליקציה אחת: האתר בכתובת `/`, ממשק הניהול בעברית בכתובת `/admin`.
מדריך העבודה המלא לקוד: `.claude/skills/mymuse-site/SKILL.md`.

## הפעלה מקומית

```bash
npm install
npm run db:local                          # מסד נתונים מקומי (PGlite, פורט 5433) – להשאיר פתוח
cp .env.example .env
LOCAL_PGLITE=1 npm run payload -- migrate
LOCAL_PGLITE=1 npm run seed               # 5 פרויקטים לדוגמה + הצהרת נגישות ופרטיות (פעם ראשונה בלבד)
npm run dev                               # http://localhost:3030  ·  ניהול: /admin
```

בכניסה הראשונה ל־`/admin` יוצרים משתמש מנהל.

## העלאה ל־Vercel

1. פרויקט חדש ב־Vercel מה־repo.
2. מחברים את האינטגרציות **Neon** (מסד נתונים) ו־**Blob** (מדיה). הן מגדירות את `DATABASE_URL` ואת `BLOB_READ_WRITE_TOKEN`. אין עוד משתנים להקליד.
3. ה־build מריץ `npm run ci`: מיגרציות ואז בנייה.
4. עד שהדומיין mymuse.co.il עובר לכאן, האתר ב־vercel.app סגור לגוגל (noindex). האתר הישן ממשיך להופיע בחיפוש עד אז.

## מה מנהלים בממשק

| בממשק | מה זה משנה באתר |
|---|---|
| **פרויקטים** | עמוד לכל פרויקט ב־`/portfolio/<כתובת>`. גוררים ברשימה כדי לשנות סדר, והסדר קובע את "הפרויקט הבא". "מוסתר באתר" מוציא פרויקט מהאתר ומהרצף. |
| **עמוד הבית** | מילות ה־Passion וצבעיהן, כותרת העבודות, כרטיסי השירותים, עלינו, לקוחות, כותרת יצירת קשר. |
| **עמודים** | הצהרת נגישות, מדיניות פרטיות ועמודי טקסט נוספים. |
| **מדיה** | תמונות וסרטונים, עם טקסט חלופי ונקודת מיקוד. |
| **הגדרות האתר** | מייל, טלפון, רשתות, צבעי עמוד הבית, תיאור ותמונת שיתוף לגוגל ולוואטסאפ. |

תצוגה חיה: בכל פרויקט, עמוד או בעמוד הבית יש כפתור תצוגה חיה (מובייל / טאבלט / דסקטופ), שמתעדכן בכל שמירה.

## הפניות מהאתר הישן

ב־`src/proxy.ts`: כל כתובות הפורטפוליו הישנות (`/portfolio/jullius-יוליוס/` וכו'), `/about-us/`, `/הצהרת-נגישות/`. פרויקט שעוד לא הועבר מפנה ל־`/#work`. כשמוסיפים אותו, מעדכנים את הכתובת החדשה ברשימה.

## נגישות

* `prefers-reduced-motion`: בלי פרלקסה, בלי מעבר אוטומטי, בלי וידאו אוטומטי. רק קישור "מעבר ל…".
* קישור דילוג לתוכן, הגדלה לא חסומה, פוקוס עובר לכותרת הפרויקט אחרי מעבר.
* פס הלקוחות עם כפתור עצירה (WCAG 2.2.2), כפתורי העתקה למייל ולטלפון.
* בצבעי פרויקט: לבדוק ניגודיות 4.5:1 בין טקסט לרקע.
